# Nelaric Unreal Gameplay API

Nelaric Unreal Gameplay is a gameplay framework for Unreal Engine 5.6 and later. Its public headers expose Pawn and Character bases, component initialization contracts, world startup configuration, and client-to-client session transitions.

Public APIs follow the [project coding standards](../CodingStandards/README.md), including the rules for gameplay extension contracts, ownership, errors, and documentation.
