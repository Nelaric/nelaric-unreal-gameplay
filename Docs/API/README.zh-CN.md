# Nelaric Unreal Gameplay API

Nelaric Unreal Gameplay 是面向 Unreal Engine 5.6 及以上版本的玩法框架。公开头文件提供 Pawn 与 Character 基础类、组件初始化契约、世界启动配置和客户端换服接口。

公开 API 遵守[项目编码规范](../CodingStandards/README.zh-CN.md)，包括玩法扩展契约、所有权、错误处理和文档要求。
