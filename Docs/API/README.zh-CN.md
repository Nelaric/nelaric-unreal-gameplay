# Nelaric Unreal Gameplay API

Nelaric Unreal Gameplay 是面向 Unreal Engine 5.6 及以上版本的玩法框架。公开契约支持在单机、监听服务器和独立服务器拓扑下开发玩法。

公开 API 遵守[项目编码规范](../CodingStandards/README.zh-CN.md)，包括玩法扩展契约、所有权、错误处理和文档要求。
